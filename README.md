
# 🍦 Ice Cream Website

A delightful single-page ice cream website featuring delicious flavours, attractive product cards, and a colourful, modern design. Created to provide an engaging and enjoyable browsing experience for ice cream lovers.

## ✨ Features

- 🏠 **Single-Page Design** – All major sections in one scrollable webpage.
- 🍨 **Flavour Showcase** – Explore a variety of delicious ice cream flavours.
- ⭐ **Best Sellers** – Discover popular and featured ice cream products.
- 🍦 **Product Categories** – Explore cups, cones, sundaes, sticks, and sandwiches.
- 🎨 **Attractive UI** – Beautiful colours, gradients, and custom CSS styling.
- 🧭 **Navigation Bar** – Easily navigate through different website sections.
- ✨ **Smooth Visual Effects** – Enhance the browsing experience with stylish transitions and animations.

## 🛠️ Tech Stack

- HTML5
- CSS
- Bootstrap
